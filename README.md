# VIChess

VIChess is an open-source chess application built with Python and Flet, providing a clean and intuitive interface for playing chess across multiple platforms.

## Features

* Local two-player (pass-and-play) gameplay
* Complete implementation of official chess rules:

  * Check and checkmate
  * Stalemate
  * Castling
  * Pawn promotion
* Cross-platform support through Flet

## Installation

```bash
pip install -r requirements.txt
```
